## Implementation
Preview sampling_strategy=3 (E), explicit experimental mode; -1 legacy and A/B/C untouched, D benchmark-only. geometry_job_limit 1..4 default2, worker start after reader; stop worker/join before source close. _geometry_jobs key→job ID unique reservations; worker.active_ids() mutex snapshot reconciles dropped/consumed jobs without retaining result arrays. Worker queue cap covers queued/running/completed; no extra consumer queue. Poll one at a time before submit; current source serial/snapshot/epoch, requested LOD and four-neighbor signature revalidated just before main-thread publication. Shared soft time budget checks before publication and before submit. Publication and submissions each have their own count limit tile_updates_per_frame, not a combined count limit. Single upload/copy can exceed soft time budget. Same generation neighbor change/removal rebuild detected by signature of last published geometry; stale work cannot overwrite current requested mesh. Last-good retained on blocked rebuild. Geometry worker still C dictionary sampler, not D. Profile dropdown E, JSON stage histograms.
