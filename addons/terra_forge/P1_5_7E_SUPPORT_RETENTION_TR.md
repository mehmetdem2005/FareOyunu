# P1.5.7e — Current physics support retention (staged)
## Root cause
Camera-only _sync_tiles selects desired tiles and frees excluded roots; _publish_geometry removes collision at LOD1/2. Player support and camera visibility are distinct. _seam can modify boundary heights when neighbor LOD changes; worker signature includes cardinal neighbors. Keeping a root alone is not a collision stability guarantee. Published shapes are distinct from page LRU; do not pin each tile's nine-page halo indefinitely.
## e1 — pure selector, CI_VERIFIED 52/52
core/support_tile_selection.gd selects <=4 unique valid support keys at LOD0 first, then ranked camera candidates. Total cap 1..128, camera input <=128. Duplicate support rejected, repeated identical camera key deduped, conflicting camera LOD rejected, overlapping support wins. Invalid or oversubscribed requests return error without partial desired set. Deterministic order follows input. Does not mutate caller arrays or existing state. New tests cover caps 1/4/8, overlap, order, release by empty support, bounds, duplicate/conflicts, invalid cap/input and immutability. No preview integration or current collision protection yet.
