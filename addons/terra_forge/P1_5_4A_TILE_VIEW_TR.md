## Implementation
core/tile_read_view.gd: short-lived main-thread-only rectangular row-major <=3x3 page view. Holds references to already validated PackedFloat32Arrays, no copied full-world data, no worker pointer or disk. Bounds on world and view; errors return no fabricated height. Internal arrays read-only by convention. Source holds at most one active view; validates unique complete rectangular page keys and full resident Float32 buffers before touching LRU once per page. Explicit release; revokes and clears all held references before poll_results (even if empty), release_outside, successful camera generation change and close. No extra retained pages across eviction; old view handles become invalid. Not a worker-safe view. 
core/paged_tile_geometry.gd generate_with_view uses unchanged generate algorithm with a view, then releases regardless of success. Preview use_tile_read_view export default false, profile checkbox and report setting. Both TFM1/TFM2. Existing source direct get_height preserved. No sampling precision/LOD/geometry policy change. Counters direct_height_reads, lru_touches (all causes), tile_view_acquires, tile_view_reads, tile_view_page_touches, tile_view_peak_pages, active_pages. These count operations, not CPU milliseconds or process RSS. Per-sample result Dictionary still exists; next phase addresses only after measurement.
