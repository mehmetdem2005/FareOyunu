## As-built
core/profile_fixture_builder.gd, separate RefCounted worker; start(dimensions), preflight(dimensions), progress(), request_cancel(), take_result(), close(). UI OptionButton 256/512/1024/2048; explicit Create isolated sample, cancel, progress; no arbitrary write path. Existing read-only user world input unchanged. Low-priority thread only disk/value APIs. Main thread polls a bounded progress dictionary; explicit close joins.
- TFR1 32x32, FILE_BYTES 4184. Logical region bytes pages*4184; TFH1 16+(cells.x+1)*(cells.y+1)*4. Conservative manifest JSON estimate 4096+160*pages plus 72 envelope. Actual disk allocation, inode overhead and temp space differ. Free-space gate estimates logical +8192/page+16MiB; not a reservation or guarantee. Actual write and final checks fail closed.
- Valid dims multiple of 32, 32..32768 for theoretical preflight. TFM1 page-count/byte bound separate from TFH1 cap 2048 per axis. 2048²=4225 pages. 3168²=10000 pages but no valid TFH1 source. 4096²=16641 pages, unsupported TFM1. 8192²=66049. No fabricated SHA or altered legacy format. Synthetic sample is deterministic analytic terrain, not production landform art.
- Source is genuine source.tfh stored inside published world, created row by row; one row Float32 buffer, one region generation buffer, one-page store cache, bounded TFM1 metadata list proportional to <=4225 pages. Independent calculations use same function and Float32 rounding. Padded region samples outside world are zero and not addressable; no fake missing-data fallback.
- Own unique user://tf_profile_fixture_<token>.staging directory; nonrecursive mkdir refuses existing; verify all TFR1 internal checks/hash and source hash before same-filesystem directory rename. Cancel cooperatively between rows/pages/verification; cancel/publication serialized. Cancellation after publication cannot undo. Cleanup only owned flat stage, rejects unexpected directories/links; reports failure path, does not scan/delete old worlds. Process kill can leave orphan staging; no automatic cleanup across sessions. GDScript FileAccess.flush + rename not proof of sudden power-loss durability. No external writer allowed.
- Profile scene fixture creation is excluded from startup benchmark. Scratch output retained for reproducibility, user must manage disk space. Existing sample and profile data retained. No new dependencies.
