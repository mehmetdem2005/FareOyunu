# TerraForge — Terrain3D runtime geçişi (T0)

Karar: özel A–I runtime motorları, mesh yayınlama, sayfa/LOD kontrolü ve deneysel scheduler'lar bu yeni runtime'da kullanılmaz. Yerlerine doğrudan MIT lisanslı TokisanGames Terrain3D v1.1.0-stable GDExtension gelir. Kaynak: https://terrain3d.readthedocs.io/en/1.1/docs/system_architecture.html ve https://github.com/TokisanGames/Terrain3D/releases/tag/v1.1.0-stable. Upstream lisans ve telif bildirimleri korunmalıdır.

Mevcut TerraForge dalı ve dosyaları değişmez. Bu izole Godot projesi gerçek native Terrain3D nesnesini oluşturur, RF Float32 örnek verisini ölçek değiştirmeden içe aktarır, sabit clipmap hedefini kameraya ve dinamik collision hedefini ayrı Node3D'ye bağlar. Veri eksikse düz zemin uydurmaz. Başlangıçta 256 piksel bölge, 0.25 m vertex spacing, mesh size 16, 5 LOD, 64 region cap, gölge kapalı: bunlar deney ayarı, performans garantisi değil. Kamera rotasında CPU mesh üretimi yapılmaz.

Kurulum: bu klasörde bash install_terrain3d.sh (gh CLI gereklidir); Godot 4.7.2 ile project.godot aç. CLI'da -- --smoke ile örnek height parity, gerçek fizik raycast ve ekran kontrolü. CI yazılımsal Vulkan/GL kontrolüdür, Android FPS değildir. APK henüz üretilmedi.

Sonraki tek iş: CI sonucunu doğrula; ardından TerraForge gerçek TFM/TFH veri formatını salt okunur doğrulanmış Float32 region import'una çevir (sınır örnekleri, koordinat, yükseklik, boşluk ve katmanları kaybetmeden). Mevcut verinin üzerine yazma. Büyük çok adalı dünya için region cap ve GPU bellek doğrulaması şarttır; tam dünyayı 64 bölgeye kırpma veya 8-bit'e indirme yasaktır. Gerçek dünya dönüştürücüsü henüz yok; şu an fixture demo çalıştırılmak üzere hazırlandı. Native Android uyumluluğu ve cihaz kare süreleri açık. Eski motor ile eşdeğer sahne karşılaştırılmadan ana dal veya eski proje değiştirilmez.

## P1.5 native world v1
Kuzey Vadisi: 2048x2048 Float32, 0.25m, 511.75x511.75m, 64 region. Fixed offline-generated original terrain only: ridges, meandering valley, gullies, foothills; no objects/water/paint. Direct launch, no source picker. The old data import is not shipped in the package. JSON report button saves user:// and opens filesystem save dialog (Android permissions may restrict copy; original remains). Raw frame intervals in microseconds, 1s summaries, draw/primitive counts, sampled RSS, physics script timing vs engine physics, ground probes, position, travel, cap and events. Recovery JSONL flush every 10s; explicit report export excludes following frame and marks events, max 1M raw frames in memory; recovery log continues. FPS cap toggle. No benchmark suite or device validation; package only. World size/region count near upstream cap, memory usage must be measured. No actual previous island design substituted: this is a new full terrain world.
## P1.5 native world v2
Dört Havza: independently generated 4096x4096 Float32, 0.25m spacing, 1023.75m square, 64 regions of 512 samples, 7 clipmap LODs, 850m camera far. 4x v1 surface area and sample count, not rescaled hills. Connected channels, basin, two ridges, plateau and coastal floor. Procedural original 512px tileable albedo maps for soil, rock, sand, grass, elevation/slope blend, no extra objects/water or legacy CPU meshes. Checkerboard debug disabled after import. All regions resident, so higher memory and startup cost expected; no false promise of streaming or phone FPS. Report FileDialog removed; direct reports/ save with user:// fallback. FPS cap switch also requests VSync off, driver may ignore. No new benchmark.
## V2 shader compatibility fix
Terrain3D automatically injects DEBUG_CHECKERED when its texture asset list is empty. This references `uv`, which the custom fragment had removed. Restore the full upstream lightweight fragment local-variable contract, apply the four custom surface textures at its end, default native texture/macro sampling off, disable checker before override and after import. No heightmap, collision, LOD or map-size changes. Android shader compilation still requires device confirmation.
